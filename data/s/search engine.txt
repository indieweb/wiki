'''<dfn>search engine</dfn>''' is a typically a service, sometimes software you can install, that given a term or phrase, searches the web or a subset thereof like your personal site, and presents instances of that term or phrase, or similar, that it found in the form of a search results page (SeRP).

If you’re looking a page about the ''search feature'' on typical personal sites, examples thereof, how to set one up to search your own personal site, user interface designs, etc. see:
* '''[[search]]'''

== Why ==
{{section-stub}}
Search engines are useful as a [[discovery]] tool to find information, and other personal websites.

== How to ==
{{section-stub}}
Typical web [[browser]]s come with at least one search engine pre-installed, you can usually install others and change which one to use as a default.

== Alternate Search Engines ==
Other, smaller or less well-known search engines used by a few folks, including a handful in the community.
* [https://marginalia-search.com/ Marginalia Search] - search engine that prioritizes non-commercial content
* [https://dkb.io/post/the-next-google The Next Google] - blogpost about how there are many people and businesses working on new takes on search that contain new ideas
* [http://www.wikigraph.net/gardensearch Wiki Graph: Search Digital Gardens] - a small search tool for searching across related "sister sites" or other [[digital garden]]s; see [https://twitter.com/BillSeitz/status/1510770230469050368 announcement]
* [https://wiby.me/ Wiby - Search Engine for the Classic Web], which indexes pages that are manually submitted
* [https://rawweb.org/ RawWeb] - search engine for personal websites
* [https://readerfunded.com/ ReaderFunded] - search engine for sites funded by readers
