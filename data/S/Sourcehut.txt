'''<dfn>[https://sr.ht Sourcehut]</dfn>''' (AKA <dfn>sr.ht</dfn>) is an open-source platform for hosting code, version control, and a build automation system.

== IndieWeb Examples ==
=== capjamesg ===

{{capjamesg}} uses chat.sr.ht, the IRC bouncer and web interface developed by Sourcehut, for interacting with IRC communities.

capjamesg formerly mirrored his Git repositories from GitHub to sr.ht using a custom script.

=== Naty S ===

{{burgeonlab}} uses: 
* [https://man.sr.ht/git.sr.ht/ git.sr.ht] for most of her remote Git repos
* [https://man.sr.ht/chat.sr.ht/ chat.sr.ht] as her [[IRC]] bouncer (which runs on [https://soju.im/ Soju])
* [https://man.sr.ht/builds.sr.ht/ builds.sr.ht] for [https://indieweb.org/continuous_integration CI/CD] of her [https://burgeonlab.com website] built with [[Hugo]]

She was looking for a GitHub alternative for (Git hosting, GitHub Pages, GitHub Actions) around mid-2025;<sup>1</sup> and chose it for the minimalist interface, fast loading/no JS, and range of services (of which some require you to be a [https://sourcehut.org/pricing/ paying subscriber]).

<sup>1</sup>: [https://burgeonlab.com/blog/migrate-github-pages-to-sourcehut-bunny/ Post about the migration.]
