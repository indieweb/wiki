This template is used to indicate an article is historical. It should be placed at the top of the page. It will also add the page to [[:Category:historical]].

== Blank Template ==
Copy and paste:

<pre style="line-height: 1.4em; padding: 1em; border: 1px solid #ddd; color: black; background-color: #f9f9f9;">{{historical}}</pre>

== Parameters ==
This template has no parameters.

== Examples ==
Including this template code:

<pre style="line-height: 1.4em; padding: 1em; border: 1px solid #ddd; color: black; background-color: #f9f9f9;">{{historical}}</pre>

Will generate:
{{historical}}
