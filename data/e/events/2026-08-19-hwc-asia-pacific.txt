=== Accessibility ===
* Morgan wrote about CSS outline that was featured in a newsletter, what I think made it good.
** https://www.morganwebdev.org/posts/outline-back/ RE CSS Outlines
** https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/outline
** https://www.morganwebdev.org/posts/outline-back/
* Check if you have a focus outline or legacy code setting outline/outline-width to 0, which is now an outdated practice
** Old, pre-2008 left-over code in many codebases
* For good [[a11y]] use <code>focus-visible</code> instead
** https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:focus-visible
*** Useful for people need visual cue (keyboard only user or low vision folks)
* Naty learnt about skip links from Morgan in the past 
* Outline doesn't shift content (DOM box model), focus-visible doesn't move anything
** https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:focus-visible
