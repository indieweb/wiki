'''<dfn>Cédric Bonhomme</dfn>''' is a computer scientist interested in computer security and privacy. He works in a Computer Emergency Response Team and contributes to open source software, mostly in Python and OCaml.

== Website ==
[https://www.cedricbonhomme.org cedricbonhomme.org] is a personal site and blog, online since 2010.

* Built with [[Hugo]], published with rsync.
* Marked up with [[h-card]].
* Full-content [[RSS]] feed; new posts are announced on [[Mastodon]] with feed2toot.
* Has a [[blogroll]] and a [[now]] page.
* Member of the [[IndieWebRing]] and of the Fediring.

== Projects ==
* [https://www.newspipe.org Newspipe], a web [[feed reader]].
* [https://www.saywhichai.org Say which AI wrote it], a practice for open source projects to declare the use of AI tools, with pages showing what the commits of a few projects declare.
* [https://www.vulnerability-lookup.org Vulnerability-Lookup], a tool to look up and correlate security vulnerabilities.
* [https://github.com/cedricbonhomme/Stegano Stegano], a Python steganography module.
