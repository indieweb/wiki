= Orbital Alchemists =

'''Orbital Alchemists''' is an independent technology studio building sovereign, decentralized personal content infrastructure, run by Simon Challinor.

== About ==

Orbital Alchemists operates infrastructure and builds tools centered on user data ownership, open file formats, and decentralized storage. The organization's flagship project is TextRoots, a modular personal content operating system designed around local-first plain text and relational data, without vendor lock-in.
