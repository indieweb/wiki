'''Myles' Clippings''' is a tool that mirrors an Are.na channel, republishing its contents as an IndieWeb-friendly gallery on your own site. The source code is [https://github.com/myles/clippings-myles-garden available on GitHub].

People using it on their own site:

* {{Myles}} is using it for [https://clippings.myles.garden clippings.myles.garden]
* ...

=== How it's made ===

The site is built with [https://astro.build Astro] and styled with [https://tailwindcss.com Tailwind CSS]. Content is pulled in via the [https://dev.are.na/documentation/rest-api Are.na API], which supplies the images and GIFs saved to the underlying channel.
