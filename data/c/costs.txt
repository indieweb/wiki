'''<dfn>Costs</dfn>''' is the amount paid to run a website, which may include a hosting provider subscription, a server, and a domain name.

== Potential costs for running a website ==

You can run a website for free using a service with a free tier. For example, you can host HTML on [[Neocities]] or [[GitHub Pages]] for free.

With that said, there are several services you may choose to use for your site which cost money. These include:

* A domain name
* A subscription to a website hosting service (i.e. [[Squarespace]], [[WordPress]], [[Ghost]])
* A server
* A place to store images and videos
* A CDN
* DNS
