A '''<dfn>custom domain name</dfn>''' is a [[domain]] which you attach to an existing [[hosting]] provider or website creation and management [[silo]].

== Benefits of a custom domain name ==
The addition of a custom domain name to to a [[silo]]-managed website adds benefits such as:
* Ability [[export]] existing [[pages]] as [[HTML]]
** Run <code>wget --mirror</code>
** Drop the [[silo]] [[hosting]]
** Upload static HTML to new hosting
* Archiving to [[Internet Archive]]
* For silos which support [[rel=me]] links, [[IndieLogin]] capabilities and other [[building blocks]]
