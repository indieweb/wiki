A '''<dfn>comments embed</dfn>''' is a bit of HTML you can [[embed]] on your site or posts to show [[comments]] on your site or posts.

There are many ways to embed comments using another site or service. Below are a few of them used by folks in the community. See the main [[comments embed]] page for a longer list.

== IndieWeb Examples ==
{{section-stub}}
Examples of IndieWeb folk using a comments embed on their personal site and/or posts:
* {{kevinmarks}} uses [[webmention.herokuapp.com]] on https://kevinmarks.com/
* {{addyourself}}

== IndieWeb comments embed services ==
* [[webmention.herokuapp.com]] — embed replies received by webmentions
* [[micro.blog]] — shows all replies to your posts on the service which supports [[Webmention]] and other IndieWeb building blocks
** https://www.manton.org/2026/11/10/littleknown-fact-microblogs-conversationjs-feature.html

== Silo comments embed services ==
Some [[silos]] have a comments embed which is used by various sites to host comments elsewhere:
* [[Disqus]] - their focus is to provide comments, discussion, and [[reacji]] sections on pages or posts.
* [[Facebook]] - see [[Facebook#Comments_Embed|Comments Embed]]
* [https://www.hypercomments.com/ HyperComments]
* Github issues and discussions can be used to host comments: See [[GitHub#Using_Github_for_comments | Using Github for comments]]
* [https://komments.cloud/ komments.cloud] is a lightweight embeddable comments system one can add to posts with an email moderation system.

== Open source comments embeds ==
Open source commenting embeds:
* [https://commento.adtac.pw commento] - go-based
** also available as a paid service: https://commento.io/
* [https://github.com/phusion/juvia Juvia] - a commenting system you can install on your own server similar to Disqus and [[Intense Debate]]
* [https://github.com/skx/e-comments/ e-comments] -  External comments for static HTML pages, a lightweight self-hosted disqus alternative.
* [http://coralproject.net/products/talk.html Mozilla Talk] - System for comment moderation and display (Javascript)
* [https://github.com/gka/schnack schnack] - nodejs-based commenting embed with oauth support
* [https://cactus.chat/ cactus.chat] - [[Python]] application with an embed for commenting using [[Matrix]]
* [https://natalie.sh/posts/bluesky-comments/ Building Bluesky Comments for My Blog] using a component to use [[Bluesky]] to integrate with [https://astro.build Astro]
* [https://hyvor.com HYVOR] has commenting as a commercial add-on which can be integrated into websites.
